<objective>
Fix the two sorter bugs found in the 2026-09-01 live-deployment review, each with a harness case in the same commit:

1. `heif_container_validate` quarantines valid camera HEIFs that carry a short trailing alignment pad after their last box (observed: `DSCF8283.HIF`, 10,502,144 bytes, three `00` bytes past `mdat`, quarantined 2026-08-28).

Purpose: the core value is that every file a camera sends either lands intact in `sorted/` or the operator is told exactly which file did not. Bug 1 loses good files to quarantine; bug 2 cries wolf and trains the operator to ignore the one signal that names a genuinely lost file.

Output: two commits, each carrying its `sort.sh` change plus its `tests/parallel-sort.sh` case, and a recorded `PASS parallel-sort` acceptance run through `tests/run-on-tower.sh`.
