<objective>
Make the panel honest about two things it currently gets wrong.

Arrival age: `/api/status` derives `age_s` from `st_mtime`, but a camera file
carries the capture mtime, so a RAW dropped ten seconds ago can report "3h in
intake" and trip the derived stuck lamp. ctime is the arrival time.

Verification: `in_library` means "a file with the same name and size exists in
`sorted/`", yet the UI calls that "an identical copy is already filed" and the
prune button deletes on that basis alone. Two different frames from the same body
can share a name and a byte count. PRODUCT.md principle 2 forbids overclaiming
verification, so the copy stops lying and `prune_verified` compares bytes before
it unlinks anything.

Purpose: OBS-02 and PANEL-01.
Output: ctime-based `age_s`, a byte-verified prune reporting `kept`, matching UI
copy, and the panel's first pytest suite.
</objective>

| Boundary | Description |
|----------|-------------|
| LAN browser to panel `/api/quarantine/action` | Unauthenticated LAN-trust write endpoint that deletes files |
| `quarantine/` and `sorted/` on the SMB-writable data mount | Any LAN client can plant files, symlinks, or races under both trees |
| local test venv install | Package-manager fetch on the developer machine |
