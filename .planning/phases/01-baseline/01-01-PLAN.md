<objective>
Put the LRU C2C folder registry that already runs in production (image `frameio-mirror:folder-lru`) onto the milestone branch's lineage by cherry-picking commit `0d566ce`, and prove the result is byte-identical to that commit.

Purpose: main currently carries the *refuse-newest* registry — when 16 folders are known it logs a warning and drops the new one. Production observation (0d566ce commit body): Camera-to-Cloud creates a folder per capture **day**, not only per device, so the newest folder is exactly the one a missed webhook needs backfilled from while a folder idle for 16 discoveries is long since mirrored. main's behaviour is backwards. This phase makes main match production, not the other way round (D-01, PROJECT.md Key Decision "LRU registry semantics win over main's refuse-newest").

Output: `frameio-mirror/app.py` and `frameio-mirror/tests/test_multi_folder.py` at the `0d566ce` content, one cherry-picked commit in `git log origin/main..HEAD`, and a recorded `57 passed` suite run.
