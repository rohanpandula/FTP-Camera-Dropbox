<objective>
Make the Frame.io suite pass on this Mac with the stock environment, by resolving every temporary directory the tests hand to the app through `os.path.realpath` before it becomes a config value — and verify the checkout cannot commit the `.impeccable/` tool directory.

Purpose: macOS's default `$TMPDIR` is `/var/folders/...`, a symlink to `/private/var/folders/...`. `frameio-mirror/app.py::_state_parent_path_is_canonical` (`os.path.realpath(parent) == str(parent)`) rejects any state parent containing a symlink — a real production protection against a swapped state directory. The tests, not the guard, are what is wrong: they hand over the symlinked path. Resolving it test-side removes the `TMPDIR=/private/tmp` crutch without weakening anything that ships (D-04).

Output: 57 passed with no `TMPDIR` override, an unchanged `app.py`, and a clean `git status`.
</objective>
